# TaskFlow - Premium Todo App

A beautiful, modern todo application built with React and Flask featuring a world-class UI with animations inspired by Apple and Notion design methodologies.

## Features

- ✨ Ultra-premium dark theme with orange gradients
- 🎨 Smooth animations and micro-interactions
- 📊 Real-time progress tracking
- 🔥 Cursor-following effects and glassmorphism UI
- 📱 Fully responsive design
- ⚡ Fast and smooth performance
- 🔧 Robust backend API

## Tech Stack

### Frontend
- React 18
- Framer Motion (animations)
- Tailwind CSS 3
- Lucide React (icons)

### Backend
- Flask (Python)
- Flask-CORS
- JSON file storage

## Getting Started

### Prerequisites
- Node.js 16+
- Python 3.9+

### Installation

**Backend:**
```bash
cd backend
python -m venv venv
source venv/bin/activate
pip install flask flask-cors
python app.py
```

**Frontend:**
```bash
cd frontend
npm install
npm start
```

The app will be available at:
- Frontend: http://localhost:3000
- Backend API: http://127.0.0.1:5000

## API Endpoints

- `GET /tasks` - Get all tasks
- `POST /tasks` - Create a new task
- `PUT /tasks/<id>` - Toggle task completion
- `DELETE /tasks/<id>` - Delete a task
- `GET /stats` - Get task statistics
